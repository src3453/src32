This repository includes the unmodified upstream gzip-compressed Plane 0
.hex source and a generated fixed-size glyph ROM. The converter maps source
records by Unicode code point, then replaces the 6,877 mapped JIS X 0208
glyphs with Jiskan16 (see assets/JISKAN16-LICENSE.txt); absent BMP code points and UTF-16 surrogate
code units use the U+FFFD replacement glyph.

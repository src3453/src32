# SGU (Sound Generator Unit) 仕様

## 1. 概要

SGUは、8チャンネルのデジタル音源とステレオ出力を提供する音源デバイスである。
各チャンネルは、256バイトの波形テーブル、PCMRAM上のPCMデータ、またはノイズを音源として選択できる。
チャンネル間の位相変調、リング変調、ハード同期、ウィンドウ変調にも対応する。

本書は、現在のCPT32エミュレータ実装に対応する仕様を定義する。未実装の機能を含む旧仕様上の音源方式や圧縮音声形式は、本仕様の対象外とする。

## 2. 音源コア

| 項目 | 仕様 |
|---|---|
| チャンネル数 | 8 |
| 波形テーブル | 1チャンネルあたり256バイト、符号なし8ビット |
| 波形モード | Wavetable、PCM、Noise、DMA PCM |
| 内部サウンドクロック | 192kHz |
| マスタークロック | 9.216MHz |
| 出力サンプルレート | 48kHz |
| 出力形式 | 16ビット符号付きリニアPCM、ステレオ |
| PCMデータ領域 | 1MiB PCMRAM |

WavetableとPCMのサンプル値は、`0x80`を無音レベルとする8ビット値として扱う。
Noiseモードは23ビットLFSRを使用する。DMA PCMモードは予約済みで、現実装では無音を出力する。

## 3. インターフェース

### 3.1 MMIO

CPUからは8ビット単位のMMIOとしてアクセスする。SGUレジスタ領域は次の通りである。

| アドレス範囲 | サイズ | 内容 |
|---|---:|---|
| `0x80020000` - `0x800207FF` | 0x800 | チャンネル0～7の波形テーブルSRAM |
| `0x80020800` - `0x800208FF` | 0x100 | チャンネル制御およびPCMレジスタ |

### 3.2 PCMRAM

| アドレス範囲 | サイズ | 内容 |
|---|---:|---|
| `0x18000000` - `0x180FFFFF` | 1MiB | PCMサンプルRAM |

PCMRAMのMMIOアドレスは、デバイス内では`0`から始まるオフセットとして扱う。範囲外の読み出しは`0`を返し、書き込みは無視する。

## 4. レジスタマップ

### 4.1 波形テーブル

チャンネル`n`（0～7）の波形テーブルは、次のアドレスに配置する。

`0x80020000 + n * 0x100 + index`（`index`: `0x00`～`0xFF`）

値は符号なし8ビットで、読み書き可能である。リセット時の全要素は`0x80`。

### 4.2 チャンネルレジスタ

チャンネル`n`の制御ブロックは、次のベースアドレスを持つ。

`base = 0x80020800 + n * 0x20`

| オフセット | レジスタ | 属性 | 内容 |
|---:|---|:---:|---|
| `0x00` | FREQUENCY_H | RW | 周波数設定値[15:8] |
| `0x01` | FREQUENCY_L | RW | 周波数設定値[7:0] |
| `0x02` | WAVEFORM | RW | 0: Wavetable、1: PCM、2: Noise、3: DMA PCM |
| `0x03` | VOLUME | RW | 音量設定値（8ビット） |
| `0x04` | PANPOT | RW | 上位ニブル: 左、下位ニブル: 右（各0～15） |
| `0x05` | MODULATION | RW | 上位5ビット: 変調方式、下位3ビット: 対象チャンネル |
| `0x06`～`0x07` | MOD_PARAM1 | RW | 変調パラメータ1（16ビット、ビッグエンディアン） |
| `0x08`～`0x09` | MOD_PARAM2 | RW | 変調パラメータ2（16ビット、ビッグエンディアン） |
| `0x0A` | PHASE_RESET | W/side effect | 位相とLFSRを初期化。読み出しでも位相を初期化し、`0`を返す |
| `0x0B` | MOD_TARGET_MODE | RW | bit0: 0=絶対指定、1=相対指定 |
| `0x0C`～`0x0F` | RESERVED | - | 未定義（読み出しは`0`、書き込みは無視） |
| `0x10`～`0x12` | PCM_START | RW | PCM開始アドレス[23:0] |
| `0x13`～`0x15` | PCM_END | RW | PCM終了アドレス[23:0] |
| `0x16`～`0x18` | PCM_LOOP | RW | PCMループアドレス[23:0] |
| `0x19` | PCM_CONTROL | RW | bit0: 再生、bit1: ループ |
| `0x1A`～`0x1F` | RESERVED | - | 未定義（読み出しは`0`、書き込みは無視） |

24ビットアドレスは各フィールドの上位バイトから順に書き込む。実装上のPCMRAMは1MiBであり、PCM読み出しアドレスは領域サイズに合わせて折り返す。

## 5. 変調

`MODULATION`の変調方式値は次の通りである。

| 値 | 方式 |
|---:|---|
| 0 | None |
| 1 | Phase |
| 2 | Ring |
| 3 | Hard Sync |
| 4 | Window |

対象チャンネルは絶対指定（0～7）、または符号付き3ビットの相対オフセットとして解釈する。相対指定では`4`～`7`を`-4`～`-1`として扱い、チャンネル番号は8チャンネル内で循環する。

## 6. 出力インターフェース

SGUは内部クロックで各出力サンプルを4回生成し、48kHzへ変換する。`clock`インターフェースはチャンネルごとの左右サンプル列を返し、`clock_mixed`インターフェースは全チャンネルを加算して左右2本の16ビットサンプル列を返す。加算結果は16ビット範囲に飽和させる。

パンポットは左右それぞれのニブルを係数として使用する。音量および内部のオーバーサンプリング係数を適用した後、左右へ振り分ける。

## 7. リセット値

リセット時、PCMRAMは全バイト`0x00`、各チャンネルの周波数・音量・変調設定・PCMアドレスは`0`、波形テーブルは全バイト`0x80`となる。PANPOTは`0xFF`、波形モードはWavetable、変調方式はNone、PCM_CONTROLは`0`である。

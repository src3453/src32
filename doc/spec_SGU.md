# SGU (Sound Generator Unit) 仕様

対象: SGU v2.1（チップ名 3WS8PNA）。v1／v2 との差と `config.yaml` での切り替えは §8 に定める。

## 1. 概要

SGUは、8チャンネルのデジタル音源とステレオ出力を提供する音源デバイスであり、システムに2個搭載する。
各チャンネルは、256バイトの波形テーブル、PCMRAM上のPCMデータ、またはノイズを音源として選択できる。
チャンネル間の位相変調、リング変調、ハード同期、ウィンドウ変調にも対応する。
2個の音源コアは独立して動作し、PCMRAMを共有する。音声出力では両コアの出力を加算する。

本書は、現在のCPT32エミュレータ実装に対応する仕様を定義する。未実装の機能を含む旧仕様上の音源方式や圧縮音声形式は、本仕様の対象外とする。

## 2. 音源コア

| 項目 | 仕様 |
|---|---|
| チャンネル数 | 8 |
| 波形テーブル | 1チャンネルあたり256バイト、符号なし8ビット |
| 波形モード | Wavetable、PCM、Noise、DMA PCM、FIFO DAC（v2.1） |
| 補間 | Wavetable／PCMは2-tap線形補間（v2.1） |
| 内部サウンドクロック | 192kHz |
| マスタークロック | 9.216MHz (デフォルト値、このシステムでは48MHz) |
| 出力サンプルレート | 48kHz |
| 出力形式 | 16ビット符号付きリニアPCM、ステレオ |
| PCMデータ領域 | 1MiB PCMRAM |

WavetableとPCMのサンプル値は、`0x80`を無音レベルとする、符号なし8ビット値として扱う。
Noiseモードは23ビットLFSRを使用する。DMA PCMモードは予約済みで、現実装では無音を出力する。

### 2.1 2-tap線形補間（v2.1）

WavetableとPCMは、位相の整数部が指す標本 `a` と次の標本 `b` を、位相の小数部（1/256単位）`f` で `a*(256-f) + b*f` と混合する（Q8.8、音量適用まで小数部を保つ）。v1／v2は `f` を無視して `a` だけを使う（1-tap、補間なし）。

- Wavetable: 次の標本はインデックス`+1`（`0xFF`の次は`0x00`）。
- PCM: 次の標本はアドレス`+1`。ただし`+1`が PCM_END 以上になる場合は、ループ有効なら PCM_LOOP の標本、無効なら現在の標本を使う（一回再生の末尾は保持）。
- Phase変調は位相の整数部へ加算する。Ring変調は補間後の値に適用する。Slew Rate／Step は補間後のQ8.8値を入力とし、v2.1では状態の小数部を出力に残す。Hard Sync／Windowの標本置換は補間しない。
- Noise、SQV4 は補間しない。

## 3. インターフェース

### 3.1 MMIO

CPUからは8ビット単位のMMIOとしてアクセスする。SGUレジスタ領域は次の通りである。

| アドレス範囲 | サイズ | 内容 |
|---|---:|---|
| `0x80020000` - `0x800207FF` | 0x800 | チャンネル0～7の波形テーブルSRAM |
| `0x80020800` - `0x800208FF` | 0x100 | チャンネル制御およびPCMレジスタ |
| `0x80021000` - `0x800217FF` | 0x800 | SGU 2のチャンネル0～7の波形テーブルSRAM |
| `0x80021800` - `0x800218FF` | 0x100 | SGU 2のチャンネル制御およびPCMレジスタ |

### 3.2 PCMRAM

| アドレス範囲 | サイズ | 内容 |
|---|---:|---|
| `0x18000000` - `0x180FFFFF` | 1MiB | 2個のSGUが共有するPCMサンプルRAM |

PCMRAMのMMIOアドレスは、デバイス内では`0`から始まるオフセットとして扱う。範囲外の読み出しは`0`を返し、書き込みは無視する。

## 4. レジスタマップ

### 4.1 波形テーブル

チャンネル`n`（0～7）の波形テーブルは、次のアドレスに配置する。

`0x80020000 + n * 0x100 + index`（`index`: `0x00`～`0xFF`）

値は符号なし8ビットで、読み書き可能である。リセット時の全要素は`0x80`。

### 4.2 チャンネルレジスタ

チャンネル`n`の制御ブロックは、次のベースアドレスを持つ。

`base = 0x80020800 + n * 0x20`

| オフセット | レジスタ | 属性 | 内容 |
|---:|---|:---:|---|
| `0x00` | FREQUENCY_H | RW | 周波数設定値[15:8] |
| `0x01` | FREQUENCY_L | RW | 周波数設定値[7:0] |
| `0x02` | WAVEFORM | RW | 0: Wavetable、1: PCM、2: Noise、3: DMA PCM、5: FIFO DAC（v2.1） |
| `0x03` | VOLUME | RW | 音量設定値（8ビット） |
| `0x04` | PANPOT | RW | 上位ニブル: 左、下位ニブル: 右（各0～15） |
| `0x05` | MODULATION | RW | 上位5ビット: 変調方式、下位3ビット: 対象チャンネル |
| `0x06`～`0x07` | MOD_PARAM1 | RW | 変調パラメータ1（16ビット、ビッグエンディアン） |
| `0x08`～`0x09` | MOD_PARAM2 | RW | 変調パラメータ2（16ビット、ビッグエンディアン） |
| `0x0A` | PHASE_RESET | W/side effect | 位相とLFSRを初期化。読み出しでも位相を初期化し、`0`を返す |
| `0x0B` | MOD_TARGET_MODE | RW | bit0: 0=絶対指定、1=相対指定 |
| `0x0C` | FIFO_DATA_H | W（v2.1） | FIFO DACデータ[15:8]。読み出しは`0` |
| `0x0D` | FIFO_DATA_L | W（v2.1） | FIFO DACデータ[7:0]。この書き込みで16ビットを1サンプルとしてFIFOへ追加 |
| `0x0E`～`0x0F` | FIFO_COUNT | R（v2.1） | FIFO内のサンプル数（16ビット、ビッグエンディアン）。書き込みは無視 |
| `0x10`～`0x12` | PCM_START | RW | PCM開始アドレス[23:0] |
| `0x13`～`0x15` | PCM_END | RW | PCM終了アドレス[23:0] |
| `0x16`～`0x18` | PCM_LOOP | RW | PCMループアドレス[23:0] |
| `0x19` | PCM_CONTROL | RW | bit0: 再生、bit1: ループ |
| `0x1A`～`0x1F` | RESERVED | - | 未定義（読み出しは`0`、書き込みは無視） |

24ビットアドレスは各フィールドの上位バイトから順に書き込む。実装上のPCMRAMは1MiBであり、PCM読み出しアドレスは領域サイズに合わせて折り返す。

### 4.3 FIFO DAC（v2.1）

`WAVEFORM=5` のチャンネルは、波形生成ではなく、チャンネルごとの FIFO から 16 ビット符号付きサンプル（2の補数）を取り出す 48kHz の DAC として動作する。FIFO は 2048 サンプル（4096 byte）で、チャンネルごとに独立する。

- 書き込み: `FIFO_DATA_H` に上位バイトを書いた後、`FIFO_DATA_L` に下位バイトを書くと 1 サンプルが追加される。FIFO が満杯のとき、追加は無視される。`FIFO_COUNT` は現在の残りサンプル数。
- 取り出しとデシメーション: `FREQUENCY`（FREQUENCY_H/L）は出力周波数ではなくデシメーション指定である。DAC は 48kHz の出力サンプルごとに 1 回動作し、`FREQUENCY` 出力サンプルのあいだ取り出した値を保持してから、次の値を取り出す（取り出し周期は `FREQUENCY + 1` 出力サンプル、実効サンプルレートは `48kHz / (FREQUENCY + 1)`）。`FREQUENCY=0` は 48kHz で毎サンプル取り出す。取り出し時点で `FREQUENCY` を読む。
- アンダーラン: 取り出し時に FIFO が空なら、前回の値を保持し、次の出力サンプルで再び取り出しを試みる。再生終了後に直流成分を残さないよう、ソフトウェアは最後に `0` を書く。
- 音量: `VOLUME` は適用されない（固定ゲイン）。値は読み書きできるが無視する。SQV4 の音量とも無関係。
- パンポット: `PANPOT` は他の音源と同様に適用する。
- 出力レベル: 値は 4 回の内部クロックで同じ値を繰り返し、§6 のマスター出力段（1/4 減衰と加算）を通る。このため満振幅（±32767）は左右 1 チャンネルで約 ±16383 になる。
- 変調（MODULATION）は無視する。他チャンネルが対象にした場合、その最終サンプルは FIFO 値の上位 8 ビットとして見える。
- `PCM_CONTROL` bit0 が 0 のときは無音で、FIFO は進まない。`PHASE_RESET` とリセットは FIFO と保持値をクリアし、デシメーションを先頭に戻す。波形モードの切り替えでは FIFO をクリアしない。
- DMAC の固定宛先転送で `FIFO_DATA_H`/`FIFO_DATA_L` へ書ける。割り込みは持たない。ソフトウェアはフレーム周期（VSync）ごとに `FIFO_COUNT` を見て補充する（60 Hz で 1 フレーム 800 サンプル）。

## 5. 変調

`MODULATION`の変調方式値は次の通りである。

| 値 | 方式 |
|---:|---|
| 0 | None |
| 1 | Phase |
| 2 | Ring |
| 3 | Hard Sync |
| 4 | Window |
| 5 | Slew Rate |
| 6 | Slew Step |

対象チャンネルは絶対指定（0～7）、または符号付き3ビットの相対オフセットとして解釈する。相対指定では`4`～`7`を`-4`～`-1`として扱い、チャンネル番号は8チャンネル内で循環する。

### Slew Rate / Slew Step

Wavetable、PCM、Noise の符号なし8ビットサンプル `x` に、音量・パン適用前の
192 kHz 内部サンプル単位で適用する。各チャンネルは Q8.8 の状態 `s` を持ち、
リセットおよび PHASE_RESET 書き込みで `0` に初期化する。
`p = MOD_PARAM1`、`d = (x << 8) - s` として次のように更新する。

- Slew Rate: `s += clamp(d, -p, p)`。
- Slew Step: `s += (d > 0 ? p : -p)`。一致時も負方向へ進むため、目標付近で振動し得る。
- 更新後 `s` を `0..(255 << 8)` に制限し、出力を `s >> 8` とする。
- `p=0` は現在値を保持する。MOD_PARAM2 と対象チャンネルは使わない。
- PCM の終端・ループ処理は通常通り適用する。DMA PCM / SQV4 へは適用しない。

### Furnace フォークとの関係

**Furnace 側の S3W2 実装はスタブであり、本仕様の規範実装ではない。**
Furnace 側の変調番号 `3/4` は Slew Rate / Slew Step であり、CPT32 の
Hard Sync / Window と一致しない。SGUB エクスポータは `3→5`、`4→6` に
変換し、対象チャンネルの下位3ビットを保持する。Furnace の予約モード `5..31`
はスタブ上で無変調として扱われるため、SGUB 出力時も None へ変換してログに
警告する。既存 CPT32 の番号 `3/4` の意味は変更しない。

スタブでは一部機能が省略・近似されているため、Furnace での試聴結果だけで
CPT32 互換性を判断しない。共有 PCMRAM、レジスタ単位、未実装機能、出力タイミング
は本仕様および `spec_SGUB.md` と CPT32 実装を基準に検証する。

## 6. 出力インターフェース

SGUは内部クロックで各出力サンプルを4回生成し、48kHzへ変換する。`clock`インターフェースはチャンネルごとの左右サンプル列を返し、`clock_mixed`インターフェースは全チャンネルを加算して左右2本の16ビットサンプル列を返す。加算結果は16ビット範囲に飽和させる。

SGUマスター出力段では、各チャンネルのサンプルをさらに1/4に減衰してからパンと加算を行う。チャンネルのVOLUMEレジスタ値やSGUBデータは変更しない。

パンポットは左右それぞれのニブルを係数として使用する。音量および内部のオーバーサンプリング係数を適用した後、左右へ振り分ける。

## 7. リセット値

リセット時、共有PCMRAMは全バイト`0x00`、両SGUの各チャンネルの周波数・音量・変調設定・PCMアドレスは`0`、波形テーブルは全バイト`0x80`となる。PANPOTは`0xFF`、波形モードはWavetable、変調方式はNone、PCM_CONTROLは`0`である。
v2.1 では FIFO と保持値も空（0）になる。

## 8. 版（v1／v2／v2.1）と設定

エミュレータは `config.yaml` の `sgu.version` で版を選ぶ。値は `1`、`2`、`2.1`（文字列でも可）で、省略時は `2.1`。両方の SGU コアに適用される。不正な値は起動時のエラーになる。

```yaml
sgu:
  version: 2.1
```

| 版 | 内容 |
|---|---|
| v1 | SGU が 1 基だけ。SGU 1 の MMIO（`0x80021000`～`0x800218FF`）は存在せず、読み出しは `0`、書き込みは無視される。PCMRAM は SGU 0 が使う。補間なし。 |
| v2 | SGU が 2 基（SGU 0／1）。補間なし（1-tap）。v2.1 導入前の実装の挙動。 |
| v2.1 | v2 に §2.1 の 2-tap 線形補間と §4.3 の FIFO DAC を加えたもの（3WS8PNA）。 |

選んだ版にない機能のレジスタは、以前の「予約」と同じに扱う。`WAVEFORM` に 5 を書くと Wavetable になり、`0x0C`～`0x0F` は読み出し `0`・書き込み無視で。ソフトウェアは `WAVEFORM` に 5 を書いて読み戻し、5 なら v2.1 と判定できる。

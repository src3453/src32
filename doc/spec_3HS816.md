# 3HS816 サウンドチップ仕様

3HS816 は 3HS88PWN4 のハーモニック音源部（8 オペレーター × 合成アルゴリズム）だけを 16 チャンネル分にしたチップです。PCM/WT/ノイズチャンネル、FIFO、EQ、コンプレッサーは持ちません。

C++ のリファレンスモデルは [`chips/3hs816/`](../chips/3hs816/) にあります。モデルは**整数演算のみ**で書かれ、RTL 実装がそのまま追えるように各段の固定小数点形式と丸めをこの文書で定めます。モデルはサウンドエンジン（`hs816::Engine`）とレジスタインタフェース（`hs816::RegisterInterface`）に分かれています。

同じコアの上に 3HS88PWN4 本体（HS 8 チャンネル + PCM/WT 4 チャンネル + フィルタ + EQ/コンプレッサー）の整数モデル [`chips/3hs88pwn4/`](../chips/3hs88pwn4/) もあります（[3HS88PWN4](#3hs88pwn4整数モデル) の節）。Furnace の S3HS と 3HS816 はこの 2 つを `src/engine/platform/sound/3hs/` に複製して使います。変更はこちらで行い、テストを通してから Furnace へ複製し直します。

## 参照元

Furnace の `src/engine/platform/sound/s3hs88pwn4/`（`sound.cpp`, `envelove.cpp`, `lib/`）。2026-11-02 に確認した `sound.cpp` の SHA-256 は `518671b1dc8a91d461c1955ccb51aa7a30a145b20e0a71c2755cc908a62c95df`。合成方式、波形、ADSR、フィードバック、パン、ミュート、出力スケールの意味を引き継ぎ、浮動小数点を固定小数点に置き換えています（差分は末尾の表）。Furnace 側ではこの浮動小数点版を整数モデルに置き換えて削除したので、比較テストに使うときは Furnace のコミット `0889f291d` から取り出します（`git -C <furnace> archive 0889f291d src/engine/platform/sound/s3hs88pwn4 | tar -x -C <dir>`）。

## 全体

| 項目 | 値 |
|---|---|
| チャンネル | 16（各 8 オペレーター） |
| 内部サンプルレート | 48,000 Hz（ホストレートへのリサンプルは呼び出し側） |
| 出力 | 16-bit 符号付きステレオ（飽和） |
| 波形 | 256 点 signed 8-bit × 16（組み込み 12 + ユーザー 4） |

## アドレスマップ

チップ相対の byte アドレス。多バイト値は big-endian。書き込みは byte 単位で即時に反映されます。

| 範囲 | 内容 |
|---|---|
| `0x000..0x3FF` | チャンネル 0..15 × 64 byte |
| `0x400..0x47F` | ユーザー波形 0..3 × 32 byte（波形 `A..D`） |
| `0x480..0x48F` | チャンネル 0..15 のミュート（0 のみ発音） |
| `0x490..0x49F` | チャンネル 0..15 のフィードバック対象オペレーター |
| `0x4A0..0x4F7` | 予約（読み書きできるが音に影響しない） |
| `0x4F8..0x4FF` | 読み出し専用 ID：ASCII `3HS816` + バージョン `01 00` |
| `0x500..` | 範囲外：read 0、write 無視 |

全レジスタはリセットで 0（ID を除く）。読み出しは最後に書いた値を返します。

### チャンネルレジスタ（base = `0x40 × ch`）

| offset | 内容 |
|---|---|
| `00..01` | OP1 周波数 F（u16, Hz。そのままの値で発音） |
| `02..0F` | OP2..OP8 の倍率 R（各 u16, Q12：4096 = 1.0） |
| `10..17` | OP1..OP8 音量（0..255） |
| `18..1B` | 波形番号、1 byte に 2 オペレーター（上位 nibble が先：`18` = OP1/OP2） |
| `1C` | アルゴリズム 0..12（13 以上は無音） |
| `1D` | パン：上位 nibble L、下位 nibble R（0..15）。両方 0 なら L=R=15 |
| `1E` | Gate（下記） |
| `1F` | フィードバック量。128 が無効、`(v−128)/128` 倍 |
| `20..3F` | OP1..OP8 の A, D, S, R（4 byte × 8） |

### Gate（`+1E`）

- `1` を書く：キーオン。8 オペレーターのエンベロープを Attack の先頭に、位相・ターン数・フィードバック履歴を 0 に戻し、Gate を on にする。Gate がすでに on でも毎回実行する（リトリガー）。
- `0` を書く：Gate が on なら 8 オペレーターを Release に入れ、Gate を off にする。off なら何もしない。
- その他の値は保存のみ。

リセット直後のエンベロープは Attack にあり、キーオンなしでも進みます（3HS88PWN4 と同じ）。音量が 0 なので無音です。

## 位相

各オペレーターは 32-bit の位相端数 `phase`（Q32、1 周 = 2^32）と、キーオンからの周回数 `turns`（0..32 で飽和）を持ちます。

1. 周波数・倍率の書き込み時：オペレーターごとのステップ `step = ceil(F × R × 2^20 / 48000)`（Q32 turns/sample。F × R/4096 / 48000 周/サンプル。OP1 は R = 4096）。F = 0 なら位相停止。F × R × 2^20 は 53 bit に収まり、48000 での除算は書き込み時だけです。最大約 22 周/サンプルなので step は 37 bit。
2. 毎サンプル：`next = phase + step`、`phase = next mod 2^32`、`turns = min(32, turns + (next >> 32))`。

周波数レジスタはそのまま Hz で、周期への量子化はしません。ステップを切り上げるのは、正確に周期的なピッチ（750 Hz は 64 サンプル/周）が毎周期ちょうど踏むテーブル境界に届くようにするためです。1 サンプルあたりの超過は 1 LSB 未満で、テーブル 1 段（2^24）よりはるかに小さい。

### ルックアップ位相とテーブル位置

ルックアップ位相は符号付き値です。

```
own   = turns × 2^32 + phase
theta = own + mod            （通常の段）
theta = mod                  （direct-phase アルゴリズムの 2 段目以降）
theta = own                  （各グループの 1 段目）
theta += fb                  （フィードバック対象オペレーターのみ）
index = trunc(theta / 2^24) mod 256   （0 方向への切り捨て）
```

0 方向の切り捨てにより、(−1/256, 1/256) 周の範囲はすべてエントリ 0 を読みます。キーオン直後（own が小さい間）と direct-phase アルゴリズムでこの不感帯が音色に効くため、3HS88PWN4 と同じにしています。変調の絶対値は最大約 20 周なので、`turns` が 32 で飽和した後は theta が常に正になり、下位 32 bit だけで決まります。

### 変調とフィードバック

オペレーター出力は `out = wave[index] × amp`（signed 8-bit × 0..255、Q15：±32640 が約 ±1.0）。

- 段の出力 `sum` は段内オペレーターの和（昇順）。次段への変調 `mod = sum × 2^19`（1.0 で 4 周）。
- フィードバック `fb = (h0 + h1) × (F1F − 128) × 2^11`。h0, h1 はそのオペレーターの直近 2 出力。`(h0+h1)/2 × (v−128)/128 × 4 周` と等価。
- 対象は `0x490+ch` の値 0..7（OP1..OP8）。それ以外の値ではフィードバックなし。
- フィードバック対象の既定は OP1、量の既定は 0（= −1 倍）。3HS88PWN4 と同じく、リセット直後は OP1 に −1 倍のフィードバックがかかる。

ルックアップ位相の幅は符号付き 40 bit あれば足ります。

## 波形

| 番号 | 波形 |
|---|---|
| 0 | sine（振幅 127） |
| 1 | 正の半波 sine |
| 2 | 前半に 1 周期 sine、後半 0 |
| 3 | 前半 127、後半 −128 の矩形 |
| 4 | 三角（1/4 周期ずらし） |
| 5 | ノコギリ（1/2 周期ずらし） |
| 6 | 前半 127、後半 0 |
| 7 | 三角の負側を 0 |
| 8 | ノコギリの負側を 0 |
| 9 | 固定ノイズ |
| A..D | ユーザー波形 0..3 |
| E | 前半に |sine| 1 周期、後半 0 |
| F | 前半に |sine| 1 周期、後半に −|sine| 1 周期 |

組み込み波形は ROM です。値は `chips/3hs816/tools/gen_tables.py` が 3HS88PWN4 の float32 計算と MT19937（seed 0、PCM ノイズ表ぶんの 65,536 回を読み捨てた後の 256 回の最下位 bit）を再現して生成し、参照実装の `sintable` と全点一致することをテストで確認しています。

ユーザー波形は 32 個の unsigned byte を 256 点へ線形補間します（末尾は先頭へ wrap）。`i = 0..255` について `pre = u[i/8]`, `next = u[(i/8+1) mod 32]`、`wave[i] = ((pre×8 + (next−pre)×(i mod 8)) >> 3) − 128`。

## 合成アルゴリズム

`A → B` は A の和で B を位相変調、`+` は和、`×` は Q15 積（`(a×b) >> 15`、算術シフト）。グループは左から順に結合します。

| mode | routing |
|---|---|
| 0 | O1+…+O8 |
| 1 | O5+O6+O7+O8 → O1+O2+O3+O4 |
| 2 | (O1+O2+O3+O4) × (O5+O6+O7+O8) |
| 3 | O7+O8 → O5+O6 → O3+O4 → O1+O2 |
| 4 | O8 → O7 → O6 → O5 → O4 → O3 → O2 → O1 |
| 5 | (O8→O7→O6→O5) + (O4→O3→O2→O1) |
| 6 | (O2→O1) + (O8→O7) + (O6→O5) + (O4→O3) |
| 7 | mode 5 の 2 系列を積 |
| 8 | (O1+O2) × (O3+O4) × (O5+O6) × (O7+O8) |
| 9 | mode 6 の 4 系列を積 |
| 10 | mode 1、キャリアは direct phase |
| 11 | mode 3、1 段目以外を direct phase |
| 12 | mode 4、1 段目以外を direct phase |

チャンネル出力 `x` は Q15 の整数で、和・積により ±2^20 程度まで広がります（符号付き 21 bit）。

## エンベロープ

各オペレーターは Attack → Decay → Sustain、Gate off で Release。時間は現在のセグメントでの経過**半サンプル数** `e` で数えます（毎サンプル +2、2^20 で飽和。21 bit）。

| セグメント | 長さ L（半サンプル） | 形 |
|---|---|---|
| Attack | 495 × A（0 なら長さ 0） | 0 → 1 線形 |
| Decay | 2250 × D（D = 0 なら 1125） | 1 → S、`1 − 2^(−10t)` |
| Release | 2250 × R（0 なら長さ 0） | 開始レベル → 0、`1 − 2^(−10t)` |

（Attack は A/64 × 0.33 秒、Decay/Release は値/64 × 1.5 秒。）

- 位置 `t = min(2^32 − 1, (e × recip(L)) >> 8)`（Q32）、`recip(L) = ceil(2^40 / L)`（32 bit。レジスタ書き込み時の除算、または値ごとの ROM）。
- Sustain レベル `S = s × 257 + (s >> 7)`（Q16、s = 0..255。s = 255 で正確に 1.0）。
- 指数部：`y = 10t`（Q32）、整数部 k、端数 f。`p = E[f>>24] − (((E[f>>24] − E[f>>24 + 1]) × ((f>>8) & 0xFFFF)) >> 16)`、`shape = 65536 − (p >> k)`、`level = from + (((to − from) × shape) >> 16)`。E は `round(2^16 × 2^(−i/256))`（i = 0..256）の ROM。
- 毎サンプル、まずレベルを計算してから `e` を進めます。`e ≥ L` ならそのセグメントを終え、`e −= L` の残りを次のセグメントへ持ち越して同じサンプルで次の式を評価します（Attack 長 0 なら即 Decay）。Release が終わった後はレベル 0。
- セグメントの途中で A/D/R を書き換えると、`e` はそのままで新しい L に対する位置が使われます（3HS88PWN4 が経過秒数を新しい長さと比べていたのと同じ）。
- キーオン：Attack、`e = 0`。レベルは次のサンプルの計算まで前の値のまま（キーオン直後の 1 サンプルは直前のレベル）。
- Release 開始：Release でなければ `e = 0`。開始レベルは常に現在のレベルを取り直す。
- 振幅：`amp = (level × 音量) >> 16`（0..255）。そのサンプルの出力に使うのは、エンベロープを進める**前**のレベル。

## 出力

各サンプルでチャンネル 0..15 を順に進め（ミュート中も状態は進む）、

```
mixL = Σ x × panL   （ミュートしていないチャンネル）
mixR = Σ x × panR
dac  = trunc(mix × 70743953 / 2^32)   （0 方向への切り捨て）
out  = clamp(dac, −32768, 32767)
```

`70743953 = 2159 × 32767`。3HS88PWN4 のスケール（チャンネル ×255×127、パン /15、ミックス /32768、DAC 32767/4）を 1 つの整数係数にまとめたもので、`32385 / 15 = 2159` なので誤差はありません。mix は符号付き 29 bit、積は 56 bit。

`ChannelOutputs` を渡すと、チャンネルごとの寄与（`x × pan` を同じ係数で DAC 単位にしたもの、飽和なし）が得られます。オシロスコープ用です。

## 3HS88PWN4（整数モデル）

`chips/3hs88pwn4/`（`hs88::Engine`, `hs88::RegisterInterface`）。ハーモニックチャンネル 0..7 は上記の 3HS816 コアそのもの（`hs816::Channel`、エンベロープ、波形 ROM、チャンネルブロックのデコード `hs816::writeChannelRegister`）です。違いは以下のとおりです。

### アドレスマップ

3HS88PWN4 本来の配置です。

| 範囲 | 内容 |
|---|---|
| `0x000000..0x3FFFFF` | PCM RAM 4 MiB（unsigned 8-bit、読み書き可） |
| `0x400000..0x4001FF` | HS チャンネル 0..7 × 64 byte（3HS816 と同じブロック） |
| `0x400200..0x4002BF` | PCM/WT チャンネル 0..3 × 48 byte |
| `0x4002C0..0x4002C7` | マスター：コンプ有効、EQ 有効、しきい値、コンプ速度、音量、EQ 低/中/高 |
| `0x4002D0..0x4002DB` | ミュート（HS 0..7、PCM 8..11。0 のみ発音） |
| `0x4003C0..0x4003C7` | HS のフィードバック対象 |
| その他 `0x400000..0x4003FF` | 予約（保存のみ） |

PCM/WT ブロック（base = `0x400200 + 48w`）：`+0..1` 周波数 F、`+2` 音量、`+3` モード、`+4` フィルタ種類、`+5` カットオフ（0 でバイパス）、`+6` レゾナンス、`+7` パン、`+8` 書き込みで同期（カーソルを 0 に。読み出しは 0）、`+10..2F` 32 byte の表（HS の波形 A..D も兼ねる。PCM モードでは先頭 9 byte が開始・終了（含む）・ループ開始の 24-bit アドレス）。

参照実装の `resetGate()` は HS の Gate への 1 の書き込みに、`wtSync()` は `+8` への書き込みになりました。FIFO（モード 5）はレジスタを持たず、エンジンの `PcmChannel::pushFifo()`（容量 4096 byte、あふれた分は捨てて -2）で入れます。

### PCM/WT チャンネル

- カーソルは整数部（64 bit）と Q32 の端数。F Hz で表 32 点を 1 周するので、1 サンプルの進みは `ceil(F × 2^32 / 1500)`（Q32、表のサンプル単位。PCM は F × 32 サンプル/秒）。F = 0 なら停止。周期への量子化はしません。
- 値（0..255）：モード 0 は PCM RAM の線形補間、1 は表の線形補間、2 は 65,536 点のノイズ（MT19937 seed 0 の最初の 65,536 回の最下位 bit、ROM）、3 はノイズ先頭 64 点、4 は表の最近傍、5 は FIFO（空なら前の値）、その他は 0。補間は `(a×65536 + (b−a)×(端数>>16)) >> 16`。
- PCM のアドレス：`start + i > end` かつ `loop < end` かつ `loop ≠ 0xFFFFFF` なら `start + i mod (end − loop)`（参照実装どおり loop を足さない）、それ以外は `min(start + i, end)`。4 MiB の外は 0。
- `x = 値 − 128`。カットオフ 0 なら出力 `x × 音量`。それ以外はフィルタ出力（Q16）× 音量 >> 16 を ±32767/−32768 で飽和。フィルタはバイパス中も動きます。
- フィルタ（直接形 I、係数 Q28、出力は ±2^30 で飽和）：`ω = 2π(cutoff+1)×8/48000` の sin, cos, ω/sin を ROM（Q30）から引き、レジスタ書き込み時に係数を整数で求めます。LP/HP の α = `sin × 16 / (17 + res)`（未定義のモードは 64/(65+res) の LP）、BP/ノッチの α = `sin × sinh(ln2 × (res+1)/256 × ω/sin)`（sinh は x⁹ までの級数、Q30）。各係数は a0 = 1+α で割って丸めます。

### ミックスとマスター

- HS：`x × pan × 2159×32767`、PCM：`r × pan × 93054785`（= round(1.3 × 32767 / (4·32768·15) × 2^32)）を 64 bit で足し、`>> 24`（0 方向）でバス（DAC 単位の Q8）にして ±2^30 で飽和。
- EQ（有効値は 1 のみ）：400 Hz ローシェルフ、1 kHz ピーキング、4 kHz ハイシェルフの直列。係数は各ゲイン値（値/8 dB）ごとの ROM（Q24）。参照実装が 44.1 kHz の既定値で設計していたのをそのまま保ちます。
- コンプレッサー（有効値は 1 のみ）：検出は |バス| の 50 Hz LPF（Q28 の ROM）。目標ゲイン（Q16）= `(しきい値 << 16) / 検出値`（しきい値 = `(値 × 32767·64 + 127) / 255`）を 256 で頭打ち。検出値 0 なら 256（しきい値も 0 なら保持）、負なら 0。ゲインは 1 サンプルに上昇 `速度×257 + (速度>>7)`、下降 4.0 まで、0..256 に制限。出力 `((バス × ゲイン) >> 16) × 音量 >> 5`。
- DAC：`バス >> 8`（0 方向）を int16 で飽和。

### 3HS88PWN4 浮動小数点版との差

ハーモニック部分は 3HS816 と同じ（下の表）。WT/PCM も周期への量子化をやめ、F Hz そのままで鳴ります（浮動小数点版は `floor(192000 / floor(192000/F))` Hz で、さらに浮動小数点の加算精度のため約 1 秒後からピッチが揺れていました）。比較テスト `hs88_legacy_compare` では、HS 全アルゴリズムとフィルタなしの WT/ノイズ全モードが ±1 LSB、PCM（ワンショットとループ）が 47〜59 dB、4 種のフィルタと未定義モードが 57〜69 dB、EQ・コンプレッサーが 57〜66 dB です（判定は 40 dB 以上）。

## 3HS88PWN4 との差

| 項目 | 3HS816 |
|---|---|
| チャンネル | HS 16、PCM/WT/ノイズ 4 チャンネルと FIFO は削除 |
| エフェクト | EQ とコンプレッサーは削除 |
| 波形 A..D | PCM/WT チャンネルの 32 byte 表の代わりに専用のユーザー波形レジスタ |
| レジスタ配置 | チャンネルが 16 に増えたため再配置（ミュート `0x480`、FB 対象 `0x490`、ID 追加） |
| 演算 | 浮動小数点をすべて固定小数点へ。位相は Q32 + 飽和ターン数 |
| 長時間の音 | 3HS88PWN4 は double 位相を float に丸めて引くため、数秒で精度が落ちる。3HS816 は何時間でも周期的 |
| Gate | 3HS88PWN4 はブロック先頭でしか 0/1 の変化を見ず、`resetGate()` は関数呼び出し。3HS816 は書き込み時に処理し、`1` の書き込みが `resetGate()` を兼ねる（Furnace のノートオンと同じ動作） |
| ピッチ | 浮動小数点版は F を 192 kHz の周期に量子化（`P = floor(192000/F)`、`192000/P` Hz）。整数モデルは量子化せず F Hz そのまま。192000 の約数の F では両者が一致する |
| 0 Hz | 3HS88PWN4 は inf を int に変換（未定義）。3HS816 は位相停止 |
| 積の丸め | float の積の代わりに Q15 積の算術シフト（±1 LSB） |

`chips/3hs816/README.md` の手順で実行します。

- `hs816_tests`：レジスタの読み書きと ID、デコード、Gate とリリース、リトリガーでの位相リセット、750 Hz を 60 秒鳴らしても周期が崩れないこと、パン・ミュート、チャンネル 0 と 15 の同一性、ユーザー波形、チャンネルタップ、エンベロープの時間と Sustain。
- `hs816_sources`：`include/` と `src/` に浮動小数点がないこと、生成テーブルが最新であること。
- `hs816_legacy_compare`（Furnace のソースがあるとき）：参照実装と同じ書き込みを 3HS816 のチャンネル 0..7 と 8..15 に行い、マスター出力を比べます。
  - **Exact**：750/375 Hz、整数倍率、平坦なエンベロープ。参照側も丸めなしで計算できる条件で、全 13 アルゴリズム・全 16 波形・パン/ミュート/飽和・FB 範囲外で **±1 LSB 以内**。
  - **Close**：エンベロープあり、FM なし（mode 0/2/8、リリースとリトリガー、途中の値変更）で **SNR 40 dB 以上**（実測 55〜74 dB）。浮動小数点版はピッチを量子化するので、比較に使う周波数は両者が一致する 192000 の約数（480, 250, 200 Hz など）に限ります。
  - **Info**：一般の FM は結果を表示するだけで判定しません。参照実装はルックアップ位相を毎回 float32 に丸める（約 1e-3 テーブル段のノイズ）ので、境界付近の判定が 3HS816 と食い違い、FM がそれを増幅します。2 段の FM（mode 1, 6, 7, 9）は 34〜62 dB で一致しますが、8 段チェーンや direct-phase（mode 3, 4, 5, 10〜12）やフィードバックの強い音では波形単位では一致しません。
- 3HS88PWN4 モデル（`chips/3hs88pwn4/README.md`）：`hs88_tests`（アドレス空間、未定義モードの DC、同期、FIFO、パン・ミュート、フィルタの上限）、`hs88_sources`、`hs88_legacy_compare`（同じ 3 段階の判定。数値は上の節）。
- Furnace 側：`python test/3hs/render_check.py build/Release/furnace.exe --reference <浮動小数点版の furnace.exe>` が実際の Furnace で S3HS と 3HS816 を鳴らし、ピッチ、全チャンネル、パン、FM、ユーザー波形、共有インストゥルメント、浮動小数点版との A/B（正弦は一致、FM 37 dB、PCM 60 dB）を確認します。

# SGU v3.1 / 3WS8PNB

SGU v3の2基の3WS8PNAを3WS8PNBに置き換える。34SI22、PCM RAM、既存レジスタの配置と動作は従来どおり。基礎仕様は [spec_SGU.md](spec_SGU.md) を参照。

## SAMPLE_CONTROL（チャンネルレジスタ +0x1A、R/W）

アドレスは SGU base + 0x800 + channel × 0x20 + 0x1A。

| ビット | 内容 |
| --- | --- |
| 1:0 | ウェーブテーブル長: 0=256、1=128、2=64、3=32サンプル |
| 2 | 補間無効: 0=2点線形補間、1=整数位置のサンプルを保持 |
| 7:3 | 予約。書き込み無視、読み出し0 |

リセット値は0（256サンプル、補間あり）。チャンネルごとに独立して設定する。PHASE_RESETでは本レジスタを変更しない。

ウェーブテーブルは各チャンネルの256バイトSRAMの先頭から指定サンプル数を使用する。32の場合、+0x00〜+0x1Fを使用し、+0x20〜+0xFFは保持・読み書き可能だが再生には使用しない。隣接チャンネルのSRAM配置は変わらない。

再生位置および位相変調後のインデックスは選択した長さでwrapする。線形補間の次点も同じ長さでwrapし、32の場合は+0x1Fから+0x00へ補間する。位相のサンプル単位とFREQUENCYによる増分は従来どおりなので、同じFREQUENCYで長さを半分にすると周期の周波数は2倍になる。HardSyncのターゲット周期判定もターゲットの設定長に従う。

補間選択はウェーブテーブル、PCM、SQV4に適用する。ノイズとFIFO DACは従来どおり。再生中の変更は次の内部サンプルから反映し、位相・SRAM・FIFO・デコーダをリセットしない。

## 互換性と設定

新レジスタに書かなければ3WS8PNAと同じ動作になる。補間無効・長さ256で3WS8PNのウェーブテーブル/PCM再生動作を選べる。旧世代モードでは+0x1Aへの書き込みを無視し、読み出しは0。

SQV4 のファイル形式は SGU v3 と共通で、ヘッダの版が 3 のファイルを再生する。版 1／2 のファイルは SGU v2.1 以前で再生する。

エミュレータの `config.yaml` で `sgu.version: 3.1` を指定できる。設定省略時は3.1。従来の1、2、2.1、3も選択可能。

この変更の実装範囲はRustエミュレータ。FPGA RTLの3WS8PNB対応は未実装。

CPT32 Fantasy Console Architecture

SRC32-based retro-modern system: Rust emulator + sol toolchain + WASM expansion

演算・映像・音響コア

  • • SRC32 CPU が MMIO で全デバイスを制御、DMA/VPU/VDPへコマンド発行
  • • VPU 固定パイプライン (Gouraud/Phong/Z-buf) を VRAM に描画
  • • VDP が PCG/GP/SGC を CLUT共有で合成、SCREEN_FILL で全消去
  • • SGU は S3W2 x2 + SQV4、PCMRAM波形、cpalへ出力

バス・割込・メディア

  • • 単一32-bitバス 4GB、Bus+BMC調停+DMAC共有、CPU/DMAC/IDC等がマスタ
  • • VSync/IRQ0 はホストフレームループ生成、CPUサイクル起因にしない
  • • Main 16MB / VRAM 4MB / PCMRAM / CHR-ROM、BIOS+ベクタテーブル
  • • IDC はスロット媒体+DMA staging、CPT32PKGは非展開・検証ロード

ホスト・拡張・開発系

  • • winit/wgpu表示、cpal音声、gilrs+tokio入力、imguiモニタ/音楽GUI
  • • PeC: ゲームパッド/タイマ/RTC/UART/RNG を集約
  • • WASM拡張 x8 (wasmtime, fuel制限、export_card! 一度だけ)
  • • sol (真=0偽=1、引数スロット規約) + asm + testbench + VSCode拡張

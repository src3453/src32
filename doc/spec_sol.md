# sol (Stack Oriented Language) 仕様書
スタックには32ビットの符号付き(リターンスタックは符号なし)数値が入る。データスタックとリターンスタックを持つ。 
文はスペースで区切られていて、左から解釈される。
ほとんどのオペレーターは短い (基本的に5文字以内) アルファベットで記述する。 
記号類は特殊な修飾子などに使われる。 
これらの文は最終的にSRC32のアセンブリにコンパイルされる。

# スタック
スタックは、LIFO (Last In First Out) のデータ構造であり、最後にプッシュされた値が最初にポップされる。スタックは、データスタックとリターンスタックの2つの部分からなる。
- データスタック: プログラムの実行中に値を格納する
- リターンスタック: サブルーチンの呼び出しと戻りのために使用される
スタックのサイズは実装に依存する。スタックオーバーフロー、スタックアンダーフローは、エラーとして扱われ、プログラムは停止する。
solには、スタックの最大サイズを取得する特別なオペレーターがある。`stacksize` は、スタックの最大サイズを返す。

# スタックへの値のプッシュ
スタックに値をプッシュするには、数値を直接書く。
例:
```
1 2 3
```

# オペレーターの使用
オペレーターはスペースで区切られた文として記述される。各オペレーターは指定された数のオペランドをスタックから取り出し、結果をスタックに置く。
例:
```
1 2 add  # 1と2を加算し、結果の3をスタックに置く
3 2 sub 2 add  # 3から2を減算し、結果の1をスタックに置き、次に1と2を加算し、結果の3をスタックに置く
```

# ラベル
コードには `@` で始まるラベルを付けることができる。ラベルはジャンプ命令のターゲットとして使われる。ラベルは一意でなければならない。
ラベル名に特殊文字を含むことはできない。

# オペレーター
## 1. 算術演算
| オペレーター | オペランド数 | 説明 |
| --- | --- | --- |
| `add` | 2 | スタックのトップ2つの値を加算し、結果をスタックに置く |
| `sub` | 2 | スタックのトップ2つの値を減算し、結果をスタックに置く |
| `mul` | 2 | スタックのトップ2つの値を乗算し、結果をスタックに置く |
| `div` | 2 | スタックのトップ2つの値を除算し、結果をスタックに置く |
| `mod` | 2 | スタックのトップ2つの値を除算し、余りをスタックに置く |
| `neg` | 1 | スタックのトップの値を符号反転し、結果をスタックに置く |
## 2. ビット演算
| オペレーター | オペランド数 | 説明 |
| --- | --- | --- |
| `and` | 2 | スタックのトップ2つの値のビットごとのANDを計算し、結果をスタックに置く |
| `or` | 2 | スタックのトップ2つの値のビットごとのORを計算し、結果をスタックに置く |
| `xor` | 2 | スタックのトップ2つの値のビットごとのXORを計算し、結果をスタックに置く |
| `not` | 1 | スタックのトップの値のビットごとのNOTを計算し、結果をスタックに置く |
| `shl` | 2 | スタックのトップの値を2つ目の値だけ左にシフトし、結果をスタックに置く |
| `shr` | 2 | スタックのトップの値を2つ目の値だけ右にシフトし、結果をスタックに置く |
## 3. スタック操作
| オペレーター | オペランド数 | 説明 |
| --- | --- | --- |
| `dup` | 1 | スタックのトップの値を複製し、スタックに置く |
| `drop` | 1 | スタックのトップの値を破棄する |
| `swap` | 2 | スタックのトップ2つの値を入れ替える |
| `over` | 2 | スタックの2つ目の値を複製し、スタックに置く |
| `rot` | 3 | スタックのトップ3つの値を回転させる (1つ目の値が3つ目に、2つ目の値が1つ目に、3つ目の値が2つ目に移動する) |
| `nip` | 2 | スタックの2つ目の値を破棄し、トップの値を残す |
| `tuck` | 2 | スタックのトップの値を2つ目の値の下に挿入する |
## 4. 比較演算
| オペレーター | オペランド数 | 説明 |
| --- | --- | --- |
| `eq` | 2 | スタックのトップ2つの値が等しいかどうかを比較し、結果をスタックに置く (1: 等しい, 0: 等しくない) |
| `neq` | 2 | スタックのトップ2つの値が等しくないかどうかを比較し、結果をスタックに置く (1: 等しくない, 0: 等しい) |
| `lt` | 2 | スタックのトップ2つの値を比較し、1つ目の値が2つ目の値より小さいかどうかを比較し、結果をスタックに置く (1: 小さい, 0: 小さくない) |
| `gt` | 2 | スタックのトップ2つの値を比較し、1つ目の値が2つ目の値より大きいかどうかを比較し、結果をスタックに置く (1: 大きい, 0: 大きくない) |
| `le` | 2 | スタックのトップ2つの値を比較し、1つ目の値が2つ目の値以下かどうかを比較し、結果をスタックに置く (1: 以下, 0: 以下でない) |
| `ge` | 2 | スタックのトップ2つの値を比較し、1つ目の値が2つ目の値以上かどうかを比較し、結果をスタックに置く (1: 以上, 0: 以上でない) |
| `sgn` | 1 | スタックのトップの値の符号ビットを取り出し、結果をスタックに置く (0: 正 (0を含む), 1: 負) |
## 5. ロード/ストア
| オペレーター | オペランド数 | 説明 |
| --- | --- | --- |
| `ld` | 1 | スタックのトップの値をアドレスとして、そこから32ビットの値をロードし、スタックに置く |
| `st` | 2 | スタックのトップの値をアドレスとして、そこへ2番目の32ビットの値をストアする |
| `ldb` | 1 | スタックのトップの値をアドレスとして、そこから8ビットの値をロードし、スタックに置く |
| `stb` | 2 | スタックのトップの値をアドレスとして、そこへ2番目の8ビットの値をストアする |
| `ldh` | 1 | スタックのトップの値をアドレスとして、そこから16ビットの値をロードし、スタックに置く |
| `sth` | 2 | スタックのトップの値をアドレスとして、そこへ2番目の16ビットの値をストアする |
## 6. リターンスタック操作
| オペレーター | オペランド数 | 説明 |
| --- | --- | --- |
| `rpush` | 1 | スタックのトップの値をリターンスタックにプッシュする |
| `rpop` | 0 | リターンスタックのトップの値をポップし、スタックに置く |
| `rpeek` | 0 | リターンスタックのトップの値を覗き見し、スタックに置く |
## 7. 制御フロー
| オペレーター | オペランド数 | 説明 |
| --- | --- | --- |
| `jmp @label` | 0 | ラベルに無条件ジャンプする |
| `jz @label` | 1 | スタックのトップの値をpopし、それが0の場合、ラベルにジャンプする |
| `jnz @label` | 1 | スタックのトップの値をpopし、それが0でない場合、ラベルにジャンプする |

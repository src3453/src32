# CSC (C Subset Compiler) 言語仕様書

本ドキュメントは、SRC32 (または SRC16) アーキテクチャをターゲットとした C 言語のサブセットコンパイラ `csc` の言語仕様を定義するものです。

## 1. 概要
CSC は C 言語の必要最小限の機能を持つサブセットです。主に32ビットアーキテクチャ(ビッグエンディアンシステム)をターゲットに想定しており、基本データ型である `int` は 32ビットとして扱われます。

## 2. 語彙規則 (Lexical Rules)

### 2.1 キーワード (予約語)
以下のキーワードが予約されています。
- `int` (32ビット整数型)
- `return`
- `if`
- `else`
- `while`

### 2.2 識別子 (Identifiers)
英字またはアンダースコア `_` で始まり、英数字またはアンダースコアが続く文字列。

### 2.3 リテラル (Literals)
- **10進数定数**: `0`〜`9` の数字の連続。
- **16進数定数**: `0x` または `0X` で始まり、`0-9`, `a-f`, `A-F` が続く文字列。

### 2.4 演算子および記号
- **算術演算子**: `+`, `-`, `*`, `/`
- **代入演算子**: `=`
- **比較演算子**: `==`, `!=`, `<=`, `>=`
- **区切り記号**: `;`, `(`, `)`, `{`, `}`
- *(※ 現在のパーサ実装では一部の比較演算・代入式はAST構築までサポートされていない状態の可能性があるため、今後の拡張箇所となります)*

### 2.5 コメント
- **単一行コメント**: `//` から行末まで。
- **複数行コメント**: `/*` から `*/` まで。

## 3. 構文規則 (Syntax Rules)

現状のパーサ実装等で解釈可能な構文の構造は以下の通りです。

### 3.1 式 (Expressions)
- **Primary Expression (一次式)**: 数値リテラル、識別子、または括弧で囲まれた式 `( expression )`
- **乗除算**: `expression * expression`, `expression / expression`
- **加減算**: `expression + expression`, `expression - expression`
*(※ 乗除算は加減算より高い優先順位を持ちます)*

### 3.2 文 (Statements)
- **式文 (Expression Statement)**:
  ```c
  expression;
  ```
- **return文**:
  ```c
  return expression;
  ```
- **if文**:
  ```c
  if ( expression ) statement
  if ( expression ) statement else statement
  ```
- **while文**:
  ```c
  while ( expression ) statement
  ```
- **ブロック (Block)**: 複数の文を波括弧で囲んだもの。
  ```c
  {
      statement1;
      statement2;
      ...
  }
  ```

## 4. 意味論 (Semantics) (実装予定)
- **型システム**: 現在は基本型として `int` (32-bit) が定義される想定です。
- **型検査**: `semantic.py` にて今後実装が行われる基盤が用意されています。

## 5. 今後の拡張実装方針
1. **比較演算・論理演算の構文解析追加**: トークナイザで認識している `==`, `!=`, `<=`, `>=` や、未サポートの `<` , `>`, `&&`, `||` のAST定義とパース処理 (`parser.py` および `csc_ast.py` への追加)。
2. **変数宣言・代入の処理**: `int x = 10;` のような変数定義と、代入式 `x = 20` のAST構築および意味解析でのスコープ管理・型チェック。
3. **関数定義および呼び出し**: 関数プロトタイプの宣言、引数の受け渡し、関数呼び出し処理の追加。

# SGUB Player: パンポットの縦バーと音量レジスタのメーター

- トラック行の右列の下段（以前の L/R 横ゲージ 2 本）を `draw_pan_volume` にまとめた。左に L/R の細い縦バー 2 本（パン 0..15、下から伸びる）、右に音量レジスタの横メーター（上段の LV/VL メーターと同じ x 範囲・24 セグメント）。SGU、34SI22（OUT の L/R 有効を 15/0、VOLUME レジスタ）、3HS の HS/WT 行が共通で使う。
- **減衰は 3HS カード（3HS816／3HS88PWN4）の行だけ**（ユーザー指定）。`Monitor::volume_meters`（キーは (カード index, チャンネル)。WT は 16+w）に `Meter` を持ち、描画のたびに `Meter::update` で上昇は即時・下降は減衰させる。ファイルを開き直すと clear する。SGU と 34SI22 はレジスタ値をそのまま `level_meter` で出す。
- HS には単一の音量レジスタがないので、最大のオペレーター音量を使う。鳴っていない（gate off、ミュート）ときは 0 を入れて減衰させる。
- 減衰の状態は描画時に更新するので、表示していないカードビューのメーターは止まったまま。
- `cargo fmt -- <file>` でも crate 全体が整形され、未変更の `bus.rs` などに差分が出る。コミット前に戻す。
- 確認: `cargo build --release --bin sgub_player` と `music.sgub` での目視（SGU ビュー）。3HS カードのビューは手元に stream がなく目視していない。
- 34SI22 の音量メーターは PLAY_VOL（チャンネルあたり 4 bit、0..15）を 15 で割る。最初は SGU と同じ 255 で割っていて、最大音量でもバーが 6% 程度にしかならなかった。レジスタの幅はデバイスごとに確かめる（SGU／3HS は 8 bit、34SI22 は 4 bit）。

# SGU の worktree 統合後の修復

- マージ後は `git grep` で追跡ファイルに残った競合マーカーを調べる。競合マーカーを含むファイルがステージ済みの場合、Git のステータスは競合を報告しない。
- SGU v3 と v3.1 は SQV4 の版 3 を再生し、SGU v2.1 以前は版 1／2 を再生する。v3.1 の SAMPLE_CONTROL で補間を切り替えてもファイル形式は変わらない。
- `cargo test --offline --lib devices::sgu` で、世代別の形式検証、フラグメント境界での補間、最終サンプルの保持、YAML の既定値を確認する。

# 34SI22A FIFO DAC（SGU v3.2）

- SGU v3.2 は v3.1（3WS8PNB×2）の 34SI22 を 34SI22A に置き換えたもの（`doc/spec_SGU_v3_2.md`、`doc/spec_34SI22.md` §11）。既定の版は 3.2。3WS8PNB の機能判定は `SguVersion::has_3ws8pnb()`（v3.1 と v3.2）を使う。v3.1 の実装は `== V3_1` で比べていたので、版を足すときは比較を述語に寄せる。
- 34SI22A は再生チャンネルごとに 2048 標本の FIFO を持つ。REC_x_ADC の上位（`0x25`／`0x27`）でラッチ、下位（`0x26`／`0x28`）で積む。読み出しは ADC のまま。FIFO_x_COUNT は `0x29`～`0x2C`。PLAY_FORMAT 5 で再生し、サンプルレートは分周レジスタに従う。アンダーランは保持して毎 tick 再試行（SGU の FIFO DAC と同じ）。
- FIFO DAC は SGU の FIFO DAC と同じく PLAY_VOL を適用しない（固定 0 dB、VOL 0 でも鳴る）。パン（L/R 出力禁止）は適用する。音量は積む側（ドライバー）で付ける。
- 停止（CTRL=0）で FIFO を空にするのは、動作中の FIFO DAC チャンネルだけ。停止中のチャンネルへの CTRL=0 や開始では空にしない（先に積んでから開始できるように）。0x0C を書くときに触らないチャンネルは 3（変更しない）にする。
- REC_FORMAT の 5 は従来どおり予約（PCM8）。`Format::from_field(value, fifo_dac)` の第 2 引数で再生側だけ FIFO DAC を許す。
- RTL は `si22 #(.FIFO_DAC(1))`（SoC 既定）。比較は `sgu_cmp.py`（34SI22A）と `sgu_cmp.py --si22-base`（34SI22）の両方で行う。ゴールデン実行ファイルは第 2 引数 `base` で 34SI22。
- Furnace フォーク（`C:/Users/y2k34/remote/furnace`）の 34SI22 は `chipType`（0: 34SI22、1: 34SI22A）で切り替え、34SI22A で Generic Sample（AMIGA）楽器を使うと、プラットフォームが Generic PCM DAC と同様に再サンプル・音量を付けて FIFO へ 16 ビット PCM を流す。

# Tang Console で /dev/fb0 を有効化

- `sys_svc_lookup`（kernel/ipc.c）の `FND_PLATFORM_TANG` 分岐が `dev.fb0` を UNSUPPORTED にしていたのを、`kernel_channel(proc, 1u)` に変更。fb ドライバ本体は共通。
- Tang の Bitmap RTL は INDEX8 のみ（`0x80000004` に非0を書くとエラーで0のまま）。BMC は VRAM 4 MiB を報告するので容量検査では弾けない。`fb_call` の `FB_SET_FORMAT` は Tang で INDEX8 以外を `FND_E_NO_MEDIA`（仕様の「実VRAMに収まらない形式」と同じ扱い）にした。
- `/dev/sgc` は Tang では UNSUPPORTED のまま。SGC の RTL コア（sgc_commands/sprites/ellipse）は診断 top（sgc_diag）にだけ接続済みで、soc_top には MMIO 0x80010000、SAT/pattern の VRAM 読出し、GP 合成が未統合。`sgc_open` は ID 不一致で NO_MEDIA を返すが、未マップ MMIO を触る危険があるため lookup 側で止めている。
- 未検証: Tang 実機ビルド・起動での fb0 動作（open/書込み/close での PCG コンソール復元）。

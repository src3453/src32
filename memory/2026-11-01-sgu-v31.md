# SGU v3.1 / 3WS8PNB

- Rust音源にV3_1とSAMPLE_CONTROL（チャンネル+0x1A）を追加。bit 1:0で256/128/64/32、bit 2で補間無効。予約ビットは無視。初期値0で3WS8PNA互換。
- チャンネルのSRAM割り当ては256バイトを維持し、指定長の先頭部分のみ再生。補間の次点と位相変調後の位置を指定長でwrapする。周波数のサンプル増分は不変。
- 補間スイッチはWavetable/PCM/SQV4に適用。旧世代では新レジスタを無視。MMIO write_registerはPCM領域への分岐より先に+0x1Aをcontrolへ送る必要がある。
- 音源ソースを直接rustc --testでコンパイルしてs3w2::testsを検証。全体cargo test --offline --lib sguはtokio 1.54.1のキャッシュ不足で失敗。
- Windows由来の.git参照が無効でコミット不可。FPGA RTLは未変更。詳細はdoc/spec_SGU_v3_1.md。

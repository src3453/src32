# SGU v3 ホスト音声入力の確認

- `config.yaml` の `sgu.version: 3` では 34SI22 が有効。ゲストが ADC レジスタを読むか録音を開始すると、エミュレータは既定の録音デバイスを遅延オープンする。
- 2026-10-30 の Windows 環境では既定の USB2 Digital Audio 入力を 48 kHz、ステレオ、f32 で開けた。実入力を SGU の PCM8 録音経路へ接続したが、4096 標本はすべて無音（0x80）だった。入力信号の存在は確認できておらず、実音声の取り込み成功を意味しない。
- `cargo test --lib devices::sgu -- --nocapture` は 36 件成功。固定ランプを用いた MMIO・PCM RAM 録音・再生のテストを含むが、ホストの実音声の確認ではない。

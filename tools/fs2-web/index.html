FS2 シリアル転送

SDカードを接続し、ほかのシリアル端末を閉じてください。COMポートと操作を指定し、ボタンを押して接続待機を開始してから、60秒以内にボードをリセットします（すでにBIOSモニターの場合は不要です）。ツールが自動的にBIOSモニターへ接続します。

待機中はシリアルに「?」を繰り返し送信します。Foundation稼働中に開始した場合、リセットまでコンソールにも入力されます。

アップロードするファイルをここへドロップ、または

イメージとディレクトリ

復元するとSDカードの先頭からイメージの範囲が上書きされます。既存データは失われます。

/

ファイルを保存（クリックまたは対応ブラウザーでドラッグ）

アップロードは既存ファイルを上書きします。転送完了まで電源や接続を切らないでください。
